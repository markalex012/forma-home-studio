# FORMA — Home Studio

A visual home fitness catalog with Russian, Hebrew (RTL), and English interfaces.

Live site: https://markalex012.github.io/forma-home-studio/

## Version 1

- 8 movement categories and 14 online video sessions
- Search and filters for video language, duration, level, and equipment
- Favorites and equipment preferences saved locally in the browser
- TV display mode and directional keyboard navigation
- Embedded YouTube player with direct YouTube fallback

Open `index.html` through an HTTP server or GitHub Pages. Internet access is required for videos, photography, and web fonts. Automatic source updates and ESP32 control are not yet connected.

Video sources belong to their respective creators. Category photography is provided by Unsplash; workout thumbnails come from YouTube.
