# FORMA TV — пробная версия 0.1

Приложение для Android TV 8.0 и новее. Целевое устройство для первой проверки: ZTE ZXV10 B866V2K с Android TV 11.

## Что работает в этой версии

- Значок и баннер FORMA TV в телевизионном меню.
- Онлайн-каталог с нашего сайта: три языка, категории, фильтры, избранное.
- Режим крупного интерфейса и навигация стрелками / OK.
- Выбранное видео открывается в приложении YouTube. Нажмите «Назад» для возврата; фактическое поведение зависит от YouTube и прошивки.
- Кнопка «Проверить YouTube» для быстрого первого теста.
- Повторная загрузка при ошибке сети.

## Установка

1. Скачайте **FORMA-TV-0.1.0.apk** из Assets этого выпуска.
2. Перенесите APK на USB-накопитель и подключите его к ZTE, либо используйте уже знакомый вам способ передачи файлов на приставку.
3. Откройте APK в файловом менеджере приставки. При запросе Android разрешите установку из этого источника для выбранного файлового менеджера.
4. Установите и откройте **FORMA TV**. Для работы требуется интернет и установленный / включённый YouTube.
5. Проверьте «Проверить YouTube», возврат кнопкой «Назад», затем выбор занятия из каталога.

Это тестовый APK с отладочной подписью. Он собран автоматически, но ещё не проверен на физической ZTE. При будущей смене подписи Android может потребовать удалить старую версию; при этом локальное избранное удалится.

Встроенный видеоплеер, управление ESP32 и автоматическое обновление источников в эту версию не входят. Видео не скачиваются. Локальное избранное приложения хранится отдельно от браузерного.

Если возникает проблема, сообщите версию Android, этап (запуск, каталог, кнопки, YouTube, возврат) и что видно на экране.
