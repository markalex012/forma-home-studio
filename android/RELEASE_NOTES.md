# FORMA Studio 1.0 — мышь и Android TV

APK: FORMA-Studio-1.0.0.apk

Полная личная версия домашней студии для ZTE ZXV10 B866V2K и других Android TV 8.0+.

## Возможности
- Интерфейс для мыши и колёсика, без ESP32.
- Русский, иврит (RTL), английский.
- Каталог из 14 исходных тренировок, категории, фильтры и избранное.
- Конструктор программ: несколько видео, изменение порядка, сохранение, удаление.
- План недели и программа на сегодня.
- Последовательное прохождение с ручной отметкой «Этап выполнен» или «Пропустить».
- История отмеченных этапов и статистика за 7 дней.
- Добавление собственных YouTube-ссылок с названием, языком, длительностью и оборудованием.
- Резервная копия JSON, копирование текста, восстановление из файла или текста.
- Ежедневная проверка метаданных общих источников. Скрытие после трёх последовательных подтверждённых ошибок отсутствия. Сетевые ошибки не считаются удалением.
- Повторная загрузка при ошибке сети.

## Установка и перенос
1. Скачайте APK, перенесите на приставку и откройте файловым менеджером.
2. При запросе Android разрешите установку для выбранного файлового менеджера.
3. Установите FORMA Studio. Пробная FORMA TV останется отдельным приложением; удалять её не требуется.
4. Для переноса избранного откройте старую FORMA TV после обновления сайта: «Настройки → Сохранить копию → Копировать текст». В новой версии используйте восстановление из текста. Новая версия также сохраняет копию в JSON-файл.
5. Проверьте запуск видео, возврат из YouTube и отметку этапа.

Видео открывается в YouTube. Возвращайтесь кнопкой «Назад». Автоматическое определение окончания и автоматический переход между видео YouTube не реализованы: отметка остаётся за вами.

Данные хранятся на устройстве; облачной синхронизации нет. Сделайте копию перед удалением. Каталог, видео и фотографии требуют интернета. Личные видео добавляются вручную; автоматического отбора качества нет.

Приложение для личной установки подписано тестовой подписью, сохраняемой в кеше сборки. При потере кеша подпись может измениться; для переустановки тогда понадобится резервная копия.

Компиляция, модульные тесты и Android lint проверяются автоматически. Версия 1.0 ещё не проверена на физической приставке; успешная работа 0.1 подтверждена пользователем.
